# עובר וסוחר

ניהול הכסף של הבית: הכנסות והוצאות, מעשרות, תקציב, מטרות חיסכון והשקעות. עובד בלי אינטרנט.

## הורדה

[להורדת התוכנה (zip)](https://github.com/tochnatorati-lab/over-vesocher/raw/main/over-vesocher.zip)

1. קליק ימני על ה-zip, "חלץ הכל".
2. בתיקייה מפעילים את "התקנה - להפעיל פעם אחת".
3. פותחים מהאייקון. התוכנה בודקת לבד אם יש גרסה חדשה.

## פרטיות

המאגר מכיל רק את קוד התוכנה. התוכנה חסומה לאינטרנט, והנתונים נשמרים רק במחשב שלכם.
בדיקת העדכונים נעשית על ידי קובץ ההפעלה, ורק מורידה את `over-vesocher.html` ו-`version.json` מכאן.
